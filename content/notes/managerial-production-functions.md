## Production function

A production function shows the maximum output obtainable from given quantities of inputs and technology. Inputs may include labour, capital, materials, land, and organisation.

## Short run and long run

In the short run at least one input is fixed. In the long run all inputs can be varied, so the firm can change plant size and technology.

## Cobb–Douglas form

A Cobb–Douglas function such as Q = A L^α K^β represents the roles of technology, labour, and capital. The exponents can help discuss returns to scale.
