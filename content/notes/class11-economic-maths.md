## Why mathematics matters

Mathematics helps economists describe relationships precisely, compare changes, and solve problems consistently. It does not replace explanation: a complete answer states what the calculation means economically.

## A repeatable numerical method

First write down the information given and identify the quantity required. Next write the relevant formula, substitute values with units, simplify carefully, and finish with a sentence interpreting the result. This process makes partial credit easier to earn and exposes arithmetic errors.

## Linear equations

A linear equation can be rearranged by performing the same operation on both sides. For example:

\[
2x + 10 = 30
\]

Subtract 10 from both sides and divide by 2, giving \(x = 10\). In an economics problem, the same steps may find an equilibrium quantity, an unknown cost, or a missing value in a schedule.

## Percentage change

Percentage change is calculated as:

\[
\text{Percentage change} = \frac{\text{new value} - \text{old value}}{\text{old value}} \times 100
\]

Always use the old value as the denominator unless the question specifies another base. A percentage increase and a percentage decrease of the same size do not return a value to its original level.

## Tables and diagrams

Read the heading, units, row labels, and column labels before calculating. In a demand or supply schedule, check whether price is rising or falling and whether the quantity changes in the expected direction. In a production table, calculate marginal values from differences between adjacent total values.

## Practice prompt

If a firm’s total cost rises from 500 to 575, calculate the percentage change. Then write one sentence explaining why a percentage result needs a clear base value.
