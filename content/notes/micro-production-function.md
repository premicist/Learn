## Production and inputs

Production transforms inputs such as labour, capital, land, materials, and organisation into goods or services. A production function describes the maximum output possible from given inputs and technology.

## Short run and long run

In the short run, at least one input is fixed. In the long run, all inputs can be varied. This time distinction is essential when interpreting output and cost changes.

## Cobb-Douglas form

A Cobb-Douglas production function can be written as **Q = A Lᵅ Kᵝ**, where technology, labour, and capital contribute to output. The exponents can help describe returns to scale.

## Productive efficiency

A production plan is technically efficient when it produces the maximum possible output from the selected inputs. Economic efficiency also considers input prices and the value of output.
